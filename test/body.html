The blind test needs JavaScript.

Method and fine print
  • Pairwise preference test with a "no difference" option, as used to evaluate speech synthesis. A and B are in random order for each visitor.
  • 60 seconds from 30 % into each episode, so the intros do not give it away; loudness normalised to −16 LUFS (EBU R 128); same format and bit rate.
  • Default settings on both sides; Vozonda used local Qwen3-TTS voices and an unedited script. Nothing was regenerated or picked.
  • One vote per pair and visitor. No cookies; duplicates are caught with a salted hash, no IP address is stored with the votes, server logs are deleted after 14 days.
  • Raw data: results.json · votes.csv, updated every five minutes.
